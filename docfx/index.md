# Overview

Microsoft.VisualStudio.Validation provides helpers for validating inputs and program state.

Install it from NuGet:

[![NuGet package](https://img.shields.io/nuget/v/Microsoft.VisualStudio.Validation.svg)](https://nuget.org/packages/Microsoft.VisualStudio.Validation)

```console
dotnet add package Microsoft.VisualStudio.Validation
```

## Highlights

- `Requires` validates method inputs.
- `Verify` checks program state.
- `Assumes` checks internal invariants.
- `Report` reports warning signs that should not throw exceptions.
